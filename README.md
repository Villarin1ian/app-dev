# Inception (2010)
### 🎬 Overview
Directed by Christopher Nolan, **Inception** is a masterclass in sci-fi filmmaking. The plot revolves around Dom Cobb, a thief who steals corporate secrets through the use of dream-sharing technology. He is given the inverse task: planting an idea into the mind of a C.E.O.
### 👥 Core Cast & Roles
**Leonardo DiCaprio** as *Dom Cobb* (The Extractor)
**Joseph Gordon-Levitt** as *Arthur* (The Point Man)
**Elliot Page** as *Ariadne* (The Architect)
**Tom Hardy** as *Eames* (The Forger)
**Cillian Murphy** as *Robert Fischer* (The Mark)
